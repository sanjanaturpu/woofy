🛠️✨

admin provisioning.

The first administrator must be created through the protected API bootstrap endpoint. This page does not create browser-local administrator accounts.

For the project developer
  1. Set WOOFY_ADMIN_SETUP_KEY in your private .env file.
  2. Start the FastAPI server and open http://127.0.0.1:8000/docs.
  3. Use POST /api/admin/bootstrap with the setup key in the X-Woofy-Setup-Key header.
  4. After the first administrator exists, this endpoint refuses further bootstrap requests. Additional admins must be created by an authenticated administrator.
