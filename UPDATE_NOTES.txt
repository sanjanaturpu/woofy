WHAT'S INCLUDED
1. Administrator dashboard
   - Overview cards for registered users, pet parents, veterinarians, pets, appointments and pending vet reviews.
   - User management with veterinarian approval/rejection and account suspend/reactivate controls.
   - Platform-wide appointment list with confirm/cancel actions.
   - Announcement composer that creates notifications for registered users in this browser.

2. Role-based dashboard experience
   - Pet Parent, Veterinarian and Administrator have separate navigation and dashboard panels.
   - Public registration offers Pet Parent and Veterinarian only.
   - Newly registered veterinarian accounts start as Pending and are excluded from parent booking/contact directories until approved.
   - Pending vets can complete clinic schedule/profile details while waiting. Rejected vets cannot access patient-facing clinic tools.
   - Suspended accounts are blocked at login/dashboard entry.
   - The dashboard refreshes the active role from the registered local account record rather than trusting only the current-session role field.

3. Notifications and care reminders
   - Appointment request, confirmation, decline and cancellation notifications.
   - New message/reply notifications.
   - Vaccination record update notifications.
   - Upcoming appointment reminder when the user opens the dashboard within 24 hours of an appointment.
   - Vaccination due-soon reminders (within 30 days) and overdue reminders.
   - Unread count, mark-as-read and mark-all-as-read controls.
   - Administrator announcements.

4. First administrator setup
   - New admin-setup.html page creates the first administrator account in the current browser.
   - Once an administrator exists in this browser, the setup form is disabled.
   - Log in with the created administrator account to access the admin dashboard.

INSTALLATION
1. Back up your current Woofy project folder.
2. Replace the five existing files listed above.
3. Add admin-setup.html beside index.html, login.html, register.html and dashboard.html.
4. Run the project with Live Server.
5. Open admin-setup.html once to create your first local administrator, then log in with that account.
6. Register a veterinarian using a separate account. Log in as admin and approve the vet under User management. Log out and log back in as the vet to see the approved clinic workspace.

IMPORTANT PROTOTYPE LIMITATIONS
- This is still a browser/localStorage prototype. It is not secure production authentication or authorization. Users can alter browser storage; real enforcement must be implemented in FastAPI on the server.
- Passwords are still stored in localStorage in the existing prototype. Do not use real or reused passwords. Password hashing and JWT/session handling belong in the backend phase.
- Admin setup is a local development bootstrap, not a secure public administrator provisioning flow. Replace it with a server-controlled process before deployment.
- Notifications are stored in the same browser. They do not sync across devices or separate browsers.
- Reminder generation runs when the relevant user's dashboard is opened. There are no background jobs, browser push notifications, email or SMS delivery yet.
- Existing veterinarian accounts without a vetApproval field are treated as approved for backwards compatibility. Newly registered vets require approval.
- The database is not connected in this update. PostgreSQL/FastAPI integration remains the next phase.
