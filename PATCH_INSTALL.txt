WOOFY UPDATE PATCH — INSTALLATION

This archive contains only changed and newly added files from the supplied
WOOFY_.zip project. It does not contain a second copy of the full project.

1. Make a backup copy of your current Woofy project folder.
2. Extract this archive directly into the existing project folder.
3. Allow Windows to replace the files with matching names.
4. Keep your real .env file private. Copy .env.example to .env only if you
   have not created .env yet, then fill in your own PostgreSQL credentials,
   WOOFY_JWT_SECRET and WOOFY_ADMIN_SETUP_KEY.
5. Install the updated Python dependencies:
      pip install -r requirements-ai.txt
6. Create a PostgreSQL database named woofy.
7. Start the backend from the project root:
      uvicorn backend.main:app --reload --port 8000
